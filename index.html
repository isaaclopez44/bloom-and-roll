Your logs, grocery checks, and routine preferences are saved in this browser on this device. No sign-in or server is used. Data may be lost if browser data is cleared. You can export a backup and import it later.

Using it on iPhone

The downloadable web-app package can be hosted on an HTTPS website and installed from Safari using Share → Add to Home Screen. The standalone HTML preview works in browsers, but local files cannot reliably install as offline home-screen apps. A hosted install can work offline after the first load.
